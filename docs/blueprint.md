# **App Name**: LinkFolio

## Core Features:

- Profile Display: Display profile image, name, bio, and links on a public interface.
- Social Link Integration: Display social media links prominently, connecting visitors to your other platforms.
- Custom Link Presentation: Showcase custom links with associated images and captions.
- Password-Protected Admin: Admin interface secured with password '2805prerna' to manage content.
- Content Editing: Enable adding, editing, and deleting profile information, links, images, and captions through the admin interface.

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5) to evoke professionalism and trust.
- Background color: Very light grayish-blue (#F0F2FA) for a clean and modern look.
- Accent color: Vibrant Cyan (#00BCD4) for interactive elements and call-to-actions.
- Headline font: 'Space Grotesk', sans-serif, for a modern and techy feel; use 'Inter', sans-serif, for body text
- Use simple, outlined icons for social media links and navigation.
- A clean, single-column layout optimized for mobile viewing, ensuring content is easily accessible.
- Subtle fade-in effects for content loading to provide a smooth user experience.
